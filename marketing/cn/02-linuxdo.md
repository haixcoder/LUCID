## 正文

最近 workflow + 一堆子代理并行跑习惯了,但一直忍不了两件事:

1. 跑的过程中完全是黑盒 —— 终端就给你转圈,哪个 agent 卡在哪步、在调什么工具、烧了多少 token,要到跑完才看得到
2. 更亏的是**它在等你你不在**:授权弹窗挂在后台会话里,你切去干别的,一停半小时

忍不了了,于是写了个插件:**Lucid**,开源,纯本机。

`/lucid` 一敲,浏览器开一个本地页面,2 秒刷一次:

- 每个 run 一张卡:phase 进度、agent 表(状态 / 最近工具 / tokens / 用时)
- 点任意一行 → 完整 prompt/result 全文抽屉(反向深扫转录拼的,不是截断预览)
- 会话监控会分「等你回答 / 疑似等你授权 / 回合正常结束」,真卡住的置顶反白 ⏸
- **飞书 webhook 推送**(通用 JSON 也支持):跑完了、或者在等你了,手机直接收到,浏览器都不用开

实现上比较强迫症的两点:

- **零依赖**:服务端纯 Python3 标准库,一行 pip 都没有;只监听 127.0.0.1;只读 Claude Code 自己落盘的状态文件,不拦截不注入不修改
- **自启动**:SessionStart 钩子 + 常驻看护,崩了自动拉起,装完之后日常就是 `/lucid` 一下

五语界面五主题(中/英/西/法/德),中文是原生不是机翻。

```

```

**回帖预案**:
- 「和 xxx 面板/官方 /workflows 视图啥区别」→ 官方面板是会话内的,这个是跨会话跨 run 总览 + 历史回看 + 飞书推送,互补;
- 「安全?」→ 只绑 127.0.0.1,唯一网络请求是你自己配的 webhook;
- 「会误报吗」→ 等授权是"疑似"档(和长命令同形),正文里就写明了,不装完美。

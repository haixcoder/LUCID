# 知乎 — 文章 + 既有问题答题

知乎策略:**答题 > 发文章**。冷启动文章没有搜索权重,而"Claude Code 怎么用/有哪些插件/子代理"类问题常年有自然流量,回答里安利最自然。外链会被知乎处理 → **仓库地址同时用纯文本写一遍**(`github.com/haixcoder/LUCID`)。

## 一、既有问题答题模板(优先做)

选题:搜"Claude Code 插件""Claude Code 效率""AI 编程 工具",挑**关注人数多、回答数还不多**的问题;写"我踩过的坑"开头,不要"最近开源了一个项目"开头。

**答题正文(300~500 字):**

```
说一个我自己在用的:多开会话 + workflow 并行子代理时,最贵的不是跑失败,而是「它在等你,你不知道」—— 授权弹窗挂在后台会话里,你切去干别的,回来发现停了半小时。

为这个我写了个开源插件 Lucid(纯本机、零依赖,只读 Claude Code 自己落盘的状态文件,不拦截不注入):

/lucid 打开本地网页,2 秒一帧看每个 agent 的阶段 / 最近工具 / tokens / 耗时;点任意一行展开完整 prompt/result 全文;会话列表自动区分「等你回答」「疑似卡在授权」「回合正常结束」,真卡住的置顶高亮,还能推飞书 —— 不开浏览器也有提醒。

安装两行:
claude plugin marketplace add haixcoder/LUCID
claude plugin install lucid@kw-dev-plugins

仓库 github.com/haixcoder/LUCID(macOS/Linux,Python3 标准库)。适合把 Claude Code 当"半自主后台"用的人。
```

**注意**:每个回答措辞要变(开头故事、结构重排),多问题复读同一段会被折叠限流;一天最多答 1~2 个。

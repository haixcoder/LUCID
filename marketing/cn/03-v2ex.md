## 正文

日常多开几个 Claude Code 会话,workflow 一跑就是十几个子代理。烦在两件事:跑的过程中是黑盒(状态要等收尾才落盘成完整 JSON,中间只能看终端转圈);以及它卡在"等你授权"的时候,你根本不知道,回来一看停了半小时。

于是写了个插件 Lucid,开源在 [github.com/haixcoder/LUCID](https://github.com/haixcoder/LUCID)。`/lucid` 打开一个本地网页,2 秒一帧:每个 run 的 phase、每个 agent 的最近工具调用 / tokens / 耗时;点任意行展开完整 prompt/result 全文;会话列表会区分「等你回答」「疑似卡在授权」「回合正常结束」,真卡住的置顶高亮,还能推飞书/通用 webhook(不开浏览器也有提醒)。

几个在意的点:

- 不拦截不注入,只读 Claude Code 自己写到 `~/.claude/projects/` 的状态文件
- 零依赖:服务端纯 Python3 标准库,没有任何 pip;只监听 127.0.0.1
- 自启动带看护,崩了自动拉起,装完日常不用管

安装两行:

```
claude plugin marketplace add haixcoder/LUCID
claude plugin install lucid@kw-dev-plugins
```

macOS / Linux。欢迎挑刺,尤其是状态推断部分 —— 没有权威 journal,「等授权」和「一条长命令还在跑」在转录里同形,目前是启发式加"疑似"标注,这块要是有更聪明的办法非常想听。

## 正文

```
同时开 4 个 Claude Code 会话的痛谁懂🥲
workflow 一跑,十几个 agent 在后台干活,
终端只给你转圈圈⭕

最贵的一次:有个 agent 第 3 分钟就在等授权确认,
我 40 分钟后才发现 —— 它干等,我白摸鱼。

后来给自己写了个插件(开源):
输入 /lucid,本地网页 2 秒一帧,实时看到——
✅ 每个 agent 的阶段/最近工具/token/耗时
✅ 点一行展开完整 prompt 和结果
✅ 哪个会话"在等你"直接置顶反白提醒
✅ 还能推飞书,不开浏览器也被戳

零依赖(纯 Python 标准库)+ 只监听本机 + 只读文件,
不拦截不注入,数据不出电脑💻

macOS/Linux,Claude Code 用户两行命令装好,
仓库地址放评论区了👇 觉得有用点个收藏~
```

## 图计划(6 张,竖版 3:4)

1. 封面:仪表盘截图加手写感大字「Claude Code 黑盒拆开了」+ ⏸ 元素;
2. 运行卡特写(phase 条 + agent 表,圈出 tokens/最近工具);
3. 全文抽屉展开前后对比("截断预览 ✕ / 完整全文 ✓");
4. ⏸ 等待高亮卡("它在等你"时刻,最有故事感);
5. 五主题拼图(颜值担当,磷光夜/冰原放前面);
6. 安装命令两行(备忘录风大字,方便保存)。

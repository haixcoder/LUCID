## Webhook 通知钩子

页面右上角 `⚙ 通知钩子`：填自定义机器人 Webhook 地址（飞书群 → 设置 → 群机器人 → 添加自定义机器人），
选格式（飞书 / 通用 JSON），勾选启用后保存。两类消息（`kind` 字段区分，飞书只有正文，靠首行图标分流）：

**① `workflow_status`** —— workflow 进入**终态**（完成/失败/被终止/未正常收尾）时推送：
任务名+状态、任务描述摘要、项目与 runId、**消费 tokens**、用时、agent 完成数、运行产物概要。`发送测试` 按钮验证。

**② `input_required`** —— 会话卡在「等你」时推送（首行 `⏸ 会话 等待回答/等待授权(疑似)/等待输入: 标题`）：
项目 · 会话、**在等**哪个工具、已静默时长 + 权限模式、最后输出预览。JSON 载荷带 `sessionId`/`waitReason`/`waitTool`/`ageSec`/`lastActivityAt`。
档位「等待输入通知」：**off** 关闭 / **blocked**（默认）只发等回答·等授权 / **all** 连每轮回合结束也发。`发送等待测试` 按钮单独验证这一类。

- 配置存 `~/.claude/cc-viewer/config.json`（含 `notifyInput` 档位）；去重状态 `sent.json`（跨重启不重发，启动首轮静默播种历史运行）。
  等待型的键是 `sess|<会话>|<本轮静默起点>`，因此**一次等待一条**：你回话→活动戳前移→再等才是新事件。
- 「等待授权」是尾窗启发式**疑似**判定（工具挂起且静默 ≥2min）——与"长命令仍在跑"在转录里同形，无权威信号可分辨。
- 通知由**服务器进程**的后台线程触发（5s 扫描），不要求浏览器页面开着；页面关了进程还在跑就会推。
- 公司 TLS 代理导致的 `CERTIFICATE_VERIFY_FAILED`：自动导出 macOS 钥匙串根证书（含 MDM 装的代理根）完成校验；
  实在不行才勾"跳过证书校验"兜底。

## Webhook 通知钩子

页面右上角 `⚙ 通知钩子`：填自定义机器人 Webhook 地址（飞书群 → 设置 → 群机器人 → 添加自定义机器人），
选格式（飞书 / 通用 JSON），勾选启用后保存。workflow 进入**终态**（完成/失败/被终止/未正常收尾）时自动推送：
任务名+状态、任务描述摘要、项目与 runId、**消费 tokens**、用时、agent 完成数、运行产物概要。`发送测试` 按钮可验证连通。

- 配置存 `~/.claude/cc-viewer/config.json`；去重状态 `sent.json`（跨重启不重发，启动首轮静默播种历史运行）。
- 通知由**服务器进程**的后台线程触发（5s 扫描），不要求浏览器页面开着；页面关了进程还在跑就会推。
- 公司 TLS 代理导致的 `CERTIFICATE_VERIFY_FAILED`：自动导出 macOS 钥匙串根证书（含 MDM 装的代理根）完成校验；
  实在不行才勾"跳过证书校验"兜底。
